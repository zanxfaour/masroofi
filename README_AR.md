# مصروفي – نسخة أولية قابلة للتشغيل

تطبيق ويب عربي (PWA) لتسجيل الدخل والمصروفات محلياً على جهازك، بدون حسابات أو اشتراكات أو API مدفوع.

## ما الموجود؟
- لوحة رصيد وإجمالي الدخل والمصروف.
- ملخص شهري وتصنيف المصروفات.
- إضافة وتعديل وحذف العمليات.
- تحليل أولي لعبارات عربية شائعة، مع مراجعة قبل الحفظ.
- تصدير نسخة JSON احتياطية.
- يعمل كتطبيق ويب قابل للإضافة إلى الشاشة الرئيسية.

## الخصوصية والحدود
- السجل محفوظ في `localStorage` داخل المتصفح على نفس الجهاز.
- لا يوجد خادم أو مزامنة سحابية.
- صدّر نسخة احتياطية دورياً. لا تمسح بيانات Safari قبل تصديرها.
- تحليل الكلام قواعد محلية وليس نموذج ذكاء اصطناعي؛ لذلك يجب مراجعة المبلغ والتصنيف قبل الحفظ.
- إدخال الصوت المباشر داخل الصفحة ليس مضموناً على كل إصدارات Safari؛ طريقة الصوت الموصى بها هي اختصار iOS Dictate Text ثم فتح رابط الصفحة مع النص في معامل `voice`.

## النشر المجاني على GitHub Pages
1. أنشئ مستودع GitHub جديداً باسم `masroofi`.
2. ارفع كل الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. من Settings > Pages اختر Deploy from a branch، ثم `main` و`/(root)`.
4. انتظر رابط GitHub Pages. يجب أن يعمل الموقع عبر HTTPS حتى يعمل التثبيت كـ PWA.

## إعداد اختصار iPhone (مصروفي صوتياً)
أنشئ Shortcut جديداً وأضف الإجراءات بالترتيب:
1. `Dictate Text` / إملاء النص. اضبط اللغة على العربية إن ظهر خيار اللغة، وأوقف الإنهاء التلقائي إذا أردت تسجيل جملة أطول.
2. `URL Encode` للنص الناتج، أو استخدم إجراء `URL` مع ترميز قيمة النص.
3. أنشئ رابطاً بالشكل:
   `https://USERNAME.github.io/masroofi/?voice=TEXT`
   واستبدل USERNAME باسم مستخدم GitHub، وTEXT بالنص بعد URL Encode.
4. أضف `Open URLs` لفتح الرابط.
5. سمّ الاختصار `مصروفي صوتياً` وضعه على الشاشة الرئيسية أو زر Action/Back Tap.

بعد فتح الصفحة تظهر مسودات العمليات. راجع كل مبلغ وتصنيف ثم اضغط «حفظ العمليات».

## النسخة الاحتياطية
اضغط زر السهم أعلى الصفحة لتنزيل ملف JSON. احتفظ به في Files أو iCloud Drive. استيراد النسخة الاحتياطية غير مفعّل في هذه النسخة الأولية.
